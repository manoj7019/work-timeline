# Work Timeline

A scrollable, date-wise timeline of everything I build. Live at **https://manoj7019.github.io/work-timeline/**

- Each piece of work sits on the date of its **first build**.
- Click a card to see the **latest version** (images, code and text preview inline), every past version, and its Claude chat, artifact, live site and repo links.
- **Add work / Add version / Edit / Delete** right on the page. Every save is a commit to this repo, so the commit history is the full change log.

## Editing from the page
Click **Connect GitHub to edit** and paste a fine-grained token with access to only this repo and
*Contents: Read and write*. The token stays in your browser's local storage.

## Files
- `entries.json` – all timeline data
- `files/<work-id>/` – uploaded files for each piece of work
